## Category words to replace with a plain phrase

| Jargon | Say instead |
| --- | --- |
| B2B | businesses that sell to other businesses |
| churn | customers who stopped buying, customers who left |
| cross-sell, upsell | sell more to the same customer, suggest the rest |
| CRM | customer list |
| AR, accounts receivable | unpaid invoices, money owed to you |
| lead | someone who might buy |
| pipeline | deals you're working on |
| onboarding | getting started |
| ROI | what you get back for what you spend |
| AI-powered, AI-native | say what it does instead |
| read-only | it only reads, it never changes anything |
